# How this profile is put together

The profile page is `README.md`. Everything it shows is a static file inside
`assets/`, generated by the scripts in `scripts/` and refreshed on a schedule by
the workflows in `.github/workflows/`. Nothing is fetched from a shared card
service at read time, so the page cannot break because someone else's server is
down.

## One-time setup

### 1. Local environment

```bash
python3.12 -m venv .venv
.venv/bin/pip install pillow numpy requests
```

### 2. A token for the metrics workflow

`lowlighter/metrics` needs a classic personal access token to read the
contribution calendar. The built-in `GITHUB_TOKEN` works but produces a thinner
calendar.

1. Create a classic PAT with scope `public_repo` (add `read:user` for private
   contribution counts).
2. Add it to this repository as a secret named `METRICS_TOKEN`.

Every workflow falls back to `github.token` if the secret is absent, so nothing
fails without it.

### 3. Let the snake workflow publish

`snake.yml` pushes to an `output` branch. Under
**Settings → Actions → General → Workflow permissions**, select
*Read and write permissions*. The branch is created on the first run.

## Regenerating things by hand

```bash
# stats card, project cards, assets/languages.json
.venv/bin/python scripts/cards.py

# both radars (reads assets/skills.json and assets/languages.json)
.venv/bin/python scripts/radar.py

# the portrait, from a photo
swift scripts/cutout.swift assets/source.jpg assets/me.png
.venv/bin/python scripts/dotify.py assets/me.png -o assets/portrait --cols 104 --equalize
```

Open `preview.html` over a local server to check every asset in both themes:

```bash
python3 -m http.server 4173
```

## What to edit

| I want to change | Edit |
|---|---|
| which projects are featured | `assets/projects.json`, then rerun `cards.py` |
| the self-rated radar | `assets/skills.json`, then rerun `radar.py` |
| colours | `scripts/theme.py` |
| how often things refresh | the `cron` lines in `.github/workflows/` |

`refresh.yml` also runs on any push that touches `scripts/` or the two JSON
files, so an edit to `projects.json` redraws the cards without waiting for the
schedule.

## A note on animation

The radars and the portrait are drawn as still SVG on purpose. Both CSS
keyframes and SMIL are ignored by renderers that show only the first frame of an
image, and a reveal animation that starts at `opacity: 0` renders there as an
empty box. `radar.py --animate` and `dotify.py --sweep` turn the reveal on if you
decide the tradeoff is worth it. The typing banner and the snake animate through
their own services and are unaffected.
